# AISDF Maturity Rubric

Score each dimension 0–5: 0 absent; 1 proposed; 2 documented; 3 locally validated; 4 independently reproduced; 5 repeatedly demonstrated across representative projects/environments. Weighted dimensions: governance 10%, documentation 10%, engine specificity 10%, schemas/contracts 10%, workflow/orchestration 10%, automated validation 10%, security/privacy 10%, tool compatibility 5%, reference-project evidence 15%, reproducibility/maintenance 10%.

A high score requires evidence artifacts, not file counts. Tool compatibility and reference-project evidence cannot score above 2 without exact environment test records. A public release cannot be called production-proven solely from documentation checks. Re-score on a dated assessment with evidence links and limitations.
