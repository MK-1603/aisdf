# Templates

Copy templates into a project workspace and replace example values. Do not commit secrets or personal data.

- `PROJECT-PROFILE.template.yaml` — short machine-readable project profile.
- `WORK-UNIT.template.yaml` — one bounded task for an AI tool or human.
- `CHECKPOINT.template.yaml` — resume point for pause/resume and handoff.
- The full human-readable project brief is the root file [`project.md`](../project.md). Copy it into your own project folder and fill it in; it covers the problem, existing-solutions check, solution, functionalities, upgrade analysis and building plan in one file. A filled-in example is in [`../examples/EXAMPLE-AI-SAAS-PROJECT.md`](../examples/EXAMPLE-AI-SAAS-PROJECT.md).
