# Mode 2 — New Project Build

**Outcome:** approved project baseline sufficient to begin implementation safely.

1. Ingest the project document and normalize requirements.
2. Detect ambiguity, contradiction, omissions and untestable requirements.
3. Identify users, roles, workflows, data classes and constraints.
4. Produce PRD, feature catalogue, acceptance criteria and traceability.
5. Define UX/UI and accessibility expectations where applicable.
6. Evaluate technology alternatives and verify exact versions/capabilities.
7. Design architecture, data/API contracts, security and operations.
8. Create milestone/task graph, permissions, approvals and test strategy.
9. Obtain baseline approval before implementation.
10. Build, verify and release through gated workflows.

The framework must not generate empty documents just to satisfy a checklist; omit irrelevant artifacts with rationale.
