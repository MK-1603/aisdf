# Mode 3 — Existing Project X-Ray & Improve

**Mandatory sequence:** Inspect → Understand → Analyze → Discover → Compare → Document → Approve → Implement → Verify.

1. Inspect repository structure, package manifests, docs, CI, tests and runtime configuration available to you.
2. Establish current behavior and baseline revision; do not assume documentation is accurate.
3. Inventory features, architecture, dependencies, data flows, integrations and known issues.
4. Identify defects, risks, gaps, duplication, stale dependencies and opportunities.
5. Compare proposed changes against current behavior and alternatives.
6. Document impact, migration, rollback, tests and approval needs.
7. Obtain approval for scope/architecture changes.
8. Implement minimal approved changes in controlled branches.
9. Verify regression, security, performance and acceptance criteria.
10. Update docs, project state and completion report.

Improvement options: preserve concept and improve execution; redesign while preserving core purpose; or transform direction/architecture with explicit approval.
