# Workforce Model

## Principles
- One task has one accountable owner; multiple specialists may contribute through explicit dependencies.
- Role contracts define responsibility; capability manifests define routable metadata; adapters provide execution.
- Workers cannot approve their own work or elevate permissions.
- Independent reviewers must not inherit the implementation conversation as their only context.
- Human project owner retains final scope, risk and release authority.
- Activate only the specialists required by project complexity.

## Maturity levels
L1 Defined; L2 Executable; L3 Verified; L4 Operational. Maturity is evidence-based and can differ by worker, adapter and environment.
