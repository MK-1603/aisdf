# Capability Maturity Model

- SPECIFIED: design or workflow documented.
- L1_DEFINED: role/contract exists.
- L2_EXECUTABLE: bounded behavior runs through an adapter.
- L3_VERIFIED: repeatable tests validate behavior and safety.
- L4_OPERATIONAL: monitored deployment, recovery, incident process and operational evidence exist.

Never promote maturity based on documentation alone. Record evidence, version, environment, evaluator and date for every promotion.
