# AISDF Mission and Scope

## Mission
Standardize and govern AI-assisted software development from problem statement to production through explicit methods, reusable contracts, evidence, approvals and lifecycle controls.

## In scope
- Problem discovery and validation; new-project definition; existing-project inspection and improvement.
- Requirements, UX/UI, technology evaluation, architecture, data/API design and security planning.
- Task decomposition, bounded delegation, handoffs, checkpoints and project-state continuity.
- Coding-tool guidance, Git/change governance, testing, independent verification, release and maintenance.
- Knowledge freshness, provenance, compatibility records and structured reporting.

## Out of scope
AISDF itself does not host models, execute code, provide a universal agent runtime, guarantee compatibility, buy/install services, own project infrastructure or deploy to production. Those actions require external tools, credentials and explicit authorization.

## Operating assumptions
A project supplies its own source of truth, owner, scope, constraints, authorized tools and approval policy. Missing critical inputs are recorded as unknowns; they are not silently invented.
