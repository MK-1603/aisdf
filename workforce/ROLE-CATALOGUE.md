# Complete AISDF Specialist Role Catalogue

AISDF 1.0.0 defines **72 specialist worker contracts** across 12 teams.

A role contract defines responsibilities. It does not mean the worker is an autonomous agent or production-certified. All current catalogue roles are `L1_DEFINED` until execution adapters and role-specific tests establish higher maturity.

## Product

- **Product Manager** (`product-manager`) — Own product outcomes, prioritization, scope proposals and decision records.
- **Business Analyst** (`business-analyst`) — Analyze stakeholders, processes, domain constraints and business rules.
- **Requirements Engineer** (`requirements-engineer`) — Create testable functional/non-functional requirements and traceability.
- **Product Analyst** (`product-analyst`) — Analyze product usage evidence and outcome metrics.
- **Technical Writer** (`technical-writer`) — Produce accurate user and developer documentation from verified behavior.

## Ux Design

- **Ux Researcher** (`ux-researcher`) — Research user needs, workflows and usability evidence.
- **Ux Designer** (`ux-designer`) — Design journeys, interaction flows and experience specifications.
- **Ui Designer** (`ui-designer`) — Design interface layouts, states and visual specifications.
- **Design Systems Engineer** (`design-systems-engineer`) — Maintain reusable design tokens, components and consistency.
- **Accessibility Specialist** (`accessibility-specialist`) — Evaluate accessibility requirements and assistive-technology behavior.

## Architecture

- **Principal Architect** (`principal-architect`) — Own cross-system architecture coherence and architecture decision records.
- **Solution Architect** (`solution-architect`) — Translate approved requirements into solution architecture and trade-offs.
- **Frontend Architect** (`frontend-architect`) — Define frontend boundaries, rendering, state and component architecture.
- **Backend Architect** (`backend-architect`) — Define service boundaries, domain logic and backend architecture.
- **Database Architect** (`database-architect`) — Own data model, consistency, migrations, indexing and storage architecture.
- **Api Architect** (`api-architect`) — Define API contracts, compatibility, versioning and integration boundaries.
- **Integration Architect** (`integration-architect`) — Design external system integration, resilience and contract boundaries.

## Frontend

- **Frontend Engineer** (`frontend-engineer`) — Implement approved web UI work within the file allowlist.
- **Web Performance Engineer** (`web-performance-engineer`) — Measure and improve web performance against agreed budgets.
- **Frontend Test Engineer** (`frontend-test-engineer`) — Verify UI behavior, browser compatibility and frontend regressions.

## Mobile

- **Mobile Engineer** (`mobile-engineer`) — Implement cross-platform mobile application features and lifecycle behavior.
- **Android Engineer** (`android-engineer`) — Implement and verify Android-specific application behavior.
- **Ios Engineer** (`ios-engineer`) — Implement and verify iOS-specific application behavior.
- **Cross Platform Engineer** (`cross-platform-engineer`) — Implement shared mobile code and platform-specific integrations.

## Backend

- **Backend Engineer** (`backend-engineer`) — Implement domain services, validation, persistence and server behavior.
- **Api Engineer** (`api-engineer`) — Implement and verify approved API contracts and integrations.
- **Distributed Systems Engineer** (`distributed-systems-engineer`) — Design and verify distributed coordination, consistency and resilience.
- **Integration Engineer** (`integration-engineer`) — Implement external integrations, adapters and failure handling.

## Data Database

- **Database Engineer** (`database-engineer`) — Implement approved schemas, queries, migrations and data integrity controls.
- **Data Engineer** (`data-engineer`) — Build data ingestion, transformation, quality and lineage workflows.
- **Data Architect** (`data-architect`) — Define analytical/operational data architecture and governance.
- **Analytics Engineer** (`analytics-engineer`) — Build reliable analytical models, metrics and data products.

## Ai Ml Agents

- **Ai Ml Engineer** (`ai-ml-engineer`) — Integrate and evaluate machine-learning models against explicit requirements.
- **Rag Engineer** (`rag-engineer`) — Design retrieval, indexing, grounding and retrieval evaluation.
- **Agent Engineer** (`agent-engineer`) — Build bounded agent tools, state, handoffs and control policies.
- **Model Evaluation Engineer** (`model-evaluation-engineer`) — Evaluate model quality, safety, cost and regression behavior.
- **Mlops Engineer** (`mlops-engineer`) — Manage model lifecycle, evaluation, deployment and monitoring.

## Security

- **Security Lead** (`security-lead`) — Own security governance, risk acceptance recommendations and security gates.
- **Application Security Engineer** (`application-security-engineer`) — Threat model applications and assess secure design and implementation.
- **Security Code Reviewer** (`security-code-reviewer`) — Review source changes for security defects and provide evidence.
- **Penetration Tester** (`penetration-tester`) — Perform explicitly authorized scoped offensive testing and validate findings.
- **Cloud Security Engineer** (`cloud-security-engineer`) — Assess cloud identity, network, workload and configuration security.
- **Iam Security Engineer** (`iam-security-engineer`) — Review authentication, authorization, identity lifecycle and privilege boundaries.
- **Devsecops Engineer** (`devsecops-engineer`) — Integrate security controls into build, test and release pipelines.
- **Supply Chain Security Engineer** (`supply-chain-security-engineer`) — Assess dependencies, SBOM, provenance, signing and build integrity.
- **Ai Security Engineer** (`ai-security-engineer`) — Assess prompt injection, tool misuse, data leakage and agent boundary risks.
- **Privacy Engineer** (`privacy-engineer`) — Assess data minimization, consent, retention, deletion and privacy controls.
- **Incident Response Engineer** (`incident-response-engineer`) — Coordinate authorized incident triage, containment and recovery evidence.
- **Independent Security Auditor** (`independent-security-auditor`) — Independently review security scope, findings, fixes and residual risk.

## Quality

- **Qa Lead** (`qa-lead`) — Own quality strategy, test coverage, release criteria and quality reporting.
- **Functional Test Engineer** (`functional-test-engineer`) — Verify user-visible and domain functionality against acceptance criteria.
- **Automation Test Engineer** (`automation-test-engineer`) — Build deterministic automated tests and regression suites.
- **Integration Test Engineer** (`integration-test-engineer`) — Verify service, API, database and external integration behavior.
- **Performance Test Engineer** (`performance-test-engineer`) — Measure load, latency, throughput and resource behavior.
- **Reliability Test Engineer** (`reliability-test-engineer`) — Test failure modes, recovery, resilience and operational readiness.
- **Independent Code Reviewer** (`independent-code-reviewer`) — Review changes independently for correctness, maintainability and scope.

## Platform Operations

- **Devops Engineer** (`devops-engineer`) — Build CI/CD and development automation within approved infrastructure scope.
- **Cloud Engineer** (`cloud-engineer`) — Provision and maintain approved cloud infrastructure and configurations.
- **Site Reliability Engineer** (`site-reliability-engineer`) — Define reliability objectives, incident readiness and operational controls.
- **Observability Engineer** (`observability-engineer`) — Implement logs, metrics, traces, dashboards and actionable alerts.
- **Network Engineer** (`network-engineer`) — Design and troubleshoot network, DNS, TLS and connectivity behavior.
- **Release Engineer** (`release-engineer`) — Prepare reproducible releases, rollout and rollback evidence.
- **Operations Engineer** (`operations-engineer`) — Maintain deployed systems, runbooks and controlled operational changes.
- **Support Engineer** (`support-engineer`) — Triage user issues and convert reproducible reports into actionable work.

## Specialized

- **Embedded Systems Engineer** (`embedded-systems-engineer`) — Design firmware and constrained-device software with hardware-aware validation.
- **Game Engineer** (`game-engineer`) — Build game systems, rendering, simulation and platform integration.
- **Blockchain Engineer** (`blockchain-engineer`) — Assess and implement distributed ledger contracts and integration where justified.
- **Robotics Engineer** (`robotics-engineer`) — Design robotics software, control interfaces and simulation/testing workflows.
- **Geospatial Engineer** (`geospatial-engineer`) — Build GIS, spatial data and geospatial processing capabilities.
- **Scientific Computing Engineer** (`scientific-computing-engineer`) — Implement reproducible numerical and scientific software workflows.
- **Compliance Engineer** (`compliance-engineer`) — Map applicable obligations to controls and verifiable evidence; no legal advice.
- **Technical Documentation Specialist** (`technical-documentation-specialist`) — Maintain architecture, API, operational and contributor documentation.
