# AISDF Functional Map

AISDF groups its capabilities into eight systems:

| System | Responsibilities |
|---|---|
| A. Project Intelligence | Intake, document ingestion, project X-Ray, baseline and state |
| B. Requirements & Product | Problem validation, stakeholders, requirements, prioritization, acceptance and traceability |
| C. Engineering Design | UX/UI, technology, architecture, data, APIs, infrastructure and decisions |
| D. Knowledge Intelligence | AKIS knowledge retrieval, freshness, evidence and source quality |
| E. Discovery & Evaluation | AFIAE discovery and evaluation of tools, APIs, SDKs, models and services |
| F. Execution & Coordination | Plans, tasks, dependencies, roles, handoffs, checkpoints, approvals and Git |
| G. Quality & Verification | Testing, review, security, performance, accessibility and independent verification |
| H. Delivery & Lifecycle | CI/CD, deployment, production verification, observability and maintenance |

An **engine** is a documented capability contract, not necessarily an agent, process, service or executable. See `engines/` for all 56 specifications.
