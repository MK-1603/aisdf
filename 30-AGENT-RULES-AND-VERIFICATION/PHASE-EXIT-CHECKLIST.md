# Phase Exit Checklist

- [ ] Phase outputs exist and match their contracts.
- [ ] Acceptance criteria evaluated with explicit statuses.
- [ ] Traceability links updated.
- [ ] Tests/reviews/evidence attached or marked NOT_RUN/BLOCKED.
- [ ] Security, privacy, accessibility and operational impacts considered.
- [ ] Deviations, assumptions and residual risks recorded.
- [ ] Required approvals obtained.
- [ ] Project state and decision log updated.
- [ ] Handoff acknowledged by receiving owner.
- [ ] Next phase entry conditions satisfied.

## Additional detail (carried from the starter seed)
- [ ] Required activities completed or explicitly dispositioned.
- [ ] Required artifacts created and validated.
- [ ] Requirements and decisions traceable.
- [ ] Required checks actually executed.
- [ ] Evidence stored and tied to the correct revision.
- [ ] Risks, defects and open questions recorded.
- [ ] No unapproved scope expansion.
- [ ] No hidden partial completion.
- [ ] Project state updated.
- [ ] Handoff package complete.
- [ ] Receiver acknowledgement/approval recorded where required.
- [ ] Exit criteria passed, or phase honestly marked blocked/failed/partial.

A phase cannot be labelled complete when a mandatory criterion is missing, failed, blocked or unverified.
