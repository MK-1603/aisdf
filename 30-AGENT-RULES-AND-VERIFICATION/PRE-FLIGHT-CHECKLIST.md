# Pre-flight Checklist

- [ ] Correct project and mode selected.
- [ ] Project baseline and current state inspected.
- [ ] Applicable governance and precedence rules loaded.
- [ ] Role, scope, permissions and prohibited actions explicit.
- [ ] Inputs and source provenance identified.
- [ ] Facts, decisions, assumptions and unknowns separated.
- [ ] Dependencies, risks and approvals identified.
- [ ] Work unit, output format and acceptance criteria defined.
- [ ] Backup/checkpoint/branch strategy appropriate to risk.
- [ ] Tool capabilities verified for required actions.
