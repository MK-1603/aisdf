# Pre-flight Checklist

- [ ] Correct project and mode selected.
- [ ] Project baseline and current state inspected.
- [ ] Applicable governance and precedence rules loaded.
- [ ] Role, scope, permissions and prohibited actions explicit.
- [ ] Inputs and source provenance identified.
- [ ] Facts, decisions, assumptions and unknowns separated.
- [ ] Dependencies, risks and approvals identified.
- [ ] Work unit, output format and acceptance criteria defined.
- [ ] Backup/checkpoint/branch strategy appropriate to risk.
- [ ] Tool capabilities verified for required actions.

## Additional detail (carried from the starter seed)
Before work starts, verify:
- [ ] Correct project and intake mode.
- [ ] Current phase and work-unit ID.
- [ ] Canonical baseline and revision.
- [ ] Applicable rules/workflow version loaded.
- [ ] User requirements and exclusions preserved.
- [ ] Facts, assumptions, inferences and unknowns separated.
- [ ] Knowledge freshness checked.
- [ ] Meaningful alternatives evaluated or omission justified.
- [ ] Inputs and dependencies available.
- [ ] Tool capabilities verified for required actions.
- [ ] Permissions are least-privileged.
- [ ] Approval requirements identified and satisfied.
- [ ] Outputs and acceptance criteria explicit.
- [ ] Verification and evidence method defined.
- [ ] Failure and recovery route known.

If a critical item fails, do not start the affected action. Resolve, ask, or mark blocked.
