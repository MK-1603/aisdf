# Governance

This directory contains AISDF's normative rules, policies and governance procedures. Read `AISDF-RULEBOOK.md` first. A rule is mandatory only when its status is `APPROVED`; `PROPOSED` content is advisory until accepted through governance.

## Precedence
Applicable law and binding organizational policy → approved project-specific constraints → approved AISDF mandatory rules → workflow/engine instructions → recommendations. A lower-level instruction cannot override a higher-level restriction. When two equally authoritative instructions conflict, stop the affected work and request an authorized decision.

## Change control
Every rule change must include an ID, rationale, scope, owner, status, effective version, compatibility impact, test/verification method and migration note when relevant.
