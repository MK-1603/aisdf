# Governance Review Checklist

- [ ] Change has an owner and rationale.
- [ ] Canonical source checked; no duplicate document introduced.
- [ ] Naming and format conventions followed.
- [ ] Rule/policy status and review date are accurate.
- [ ] Cross-references and indexes updated.
- [ ] Security, privacy and compatibility impacts considered.
- [ ] Required tests and evidence attached.
- [ ] Exceptions have authorized, time-bounded waivers.
