# AISDF Definitions

**Status:** APPROVED

- **Framework rule:** normative requirement applicable to AISDF work or repository contributions.
- **Policy:** operational statement explaining how a class of risks or activities is governed.
- **Engine:** documented capability specification; not necessarily executable software or an autonomous agent.
- **Workflow:** ordered procedure with inputs, outputs, gates, roles and exit conditions.
- **Evidence:** reproducible artifact or observation supporting a claim.
- **Adapter:** documented integration boundary to an external tool or service.
- **Verified capability:** capability tested against a stated version, environment and date with retained evidence.
- **Waiver:** time-bounded, authorized exception with rationale and residual-risk owner.
