# Engine Specification Standard

Every engine must define: stable ID/title; purpose; scope/non-goals; trigger; required inputs; output contract; engine-specific procedure; decision rules; dependencies; responsible role; permitted capabilities; safety boundaries; failure behavior; evidence; acceptance criteria; exit criteria; minimum test scenarios; version/status/owner.

Generic text may establish shared controls but cannot replace engine-specific logic. An engine is `SPECIFIED` when its contract is complete, `TESTED` when its test scenarios have reproducible results, and `VERIFIED` only when evidence demonstrates the stated capability in a named environment. Documentation alone does not prove execution.
