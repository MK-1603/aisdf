# Release Readiness Checklist

- [ ] Version and changelog updated.
- [ ] Repository validator passes.
- [ ] All JSON schemas validate.
- [ ] Valid and invalid fixtures are tested.
- [ ] Workflow tests pass or deviations are disclosed.
- [ ] Internal links resolve.
- [ ] No secrets or private data are committed.
- [ ] License decision and security contact are finalized for public release.
- [ ] Known limitations and unverified adapters are disclosed.
- [ ] Maintainer approval recorded.
