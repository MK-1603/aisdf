# MK Framework

The MK Framework is a venture-to-software execution method that connects idea validation, risk control, product definition, disciplined software delivery, feedback, reinvestment, moat defense, and systemization.

It is included in AISDF as an **optional venture and product execution methodology**. AISDF remains the broader software engineering framework; MK Framework adds an upstream decision process for deciding what is worth building and a downstream process for learning, scaling, or stopping.

## Start here

1. Read [`MK-FRAMEWORK.md`](MK-FRAMEWORK.md) for the complete written method.
2. Review [`assets/MK-FRAMEWORK-OVERVIEW.png`](assets/MK-FRAMEWORK-OVERVIEW.png) for the visual flow.
3. Apply the gates to a specific venture or project. Record evidence and thresholds; do not treat a passed stage as a feeling-based judgment.
4. When the decision is to build software, connect the approved scope to AISDF's project lifecycle: `PROJECT.md`, `AGENTS.md`, WF-013, implementation planning, approval, implementation, and verification.

## Relationship to AISDF

- **MK Framework:** Should we pursue this opportunity, what should we offer, how do we build it, and how do we learn or systemize?
- **AISDF:** How do we engineer, govern, implement, test, secure, release, and maintain the software responsibly?

The MK Framework does not replace AISDF governance, security, verification, or human approval gates.
