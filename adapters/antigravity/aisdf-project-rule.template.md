# AISDF project workspace rule

Read `AGENTS.md` and `PROJECT.md` before project work. PROJECT.md is the product/engineering source of truth; AGENTS.md is the agent operating contract. Read the active approved implementation plan and obey its exact file allowlist. Assessment is read-only. Do not modify application source until explicit human approval is recorded. Preserve existing rules, run relevant tests, and report actual evidence. If independent review isolation cannot be demonstrated, label it NON_INDEPENDENT or BLOCKED.
