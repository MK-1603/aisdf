# OpenAI Codex Adapter

This adapter packages an AISDF skill under `.agents/skills/aisdf/SKILL.md`.

## Install
1. Review existing root and nested `AGENTS.md` instructions.
2. Copy/merge `.agents/skills/aisdf/SKILL.md` into the target repository.
3. Keep the target project's root `PROJECT.md` as project truth and `AGENTS.md` as the agent operating contract.
4. Ask Codex to summarize the loaded instructions and verify the skill is discoverable in the installed version.

Do not overwrite user-authored instructions. Host discovery behavior must be verified in the actual environment; this adapter is not live-certified.
