# Cursor Adapter

This adapter packages an AISDF Cursor rule in `.cursor/rules/aisdf.mdc` and a project-rule template.

## Install
1. Review existing `.cursor/rules/`, `AGENTS.md`, and `PROJECT.md`.
2. Copy/merge `.cursor/rules/aisdf.mdc` into the target repository.
3. Keep `PROJECT.md` and `AGENTS.md` as shared canonical project/agent documents.
4. Open Cursor and verify the rule is enabled and applied to the intended files.

Do not overwrite existing rules. Verify behavior in the installed Cursor version; this adapter is not live-certified.
