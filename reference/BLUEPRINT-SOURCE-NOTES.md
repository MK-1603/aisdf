# Blueprint Source Notes

This repository build was structured from the AISDF master blueprint v3.0 and its earlier functional, repository and engine/rule source documents supplied in the working session. The 56 engine IDs, names and responsibility summaries are transcribed from the master blueprint's “Complete engine catalogue — 56 engines” section. Each detailed engine file is an operational contract expansion of that catalogue and should be reviewed against the full source blueprint before being treated as final normative guidance.

The full blueprint is retained outside this repository build as a working source artifact; this file records provenance without copying the entire blueprint into the canonical repository.
