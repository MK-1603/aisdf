# Version and Compatibility Matrix

For each selected technology record: product/component, exact version, supported runtime/OS, package manager, framework peers, database/API compatibility, supported deployment targets, license, support window, known constraints, source URLs, checked date and reviewer.

Compatibility states: VERIFIED (tested exact combination), PARTIAL (some paths tested), REPORTED (source claims, not locally tested), EXPERIMENTAL, NOT_VERIFIED, INCOMPATIBLE, DEPRECATED. A matrix entry must include test evidence for VERIFIED. Do not infer compatibility from “latest” or from a vendor logo.
