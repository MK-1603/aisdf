# WF-003 — Work Unit and Handoff Lifecycle

1. Coordinator creates a work unit with objective, scope, owner, inputs, dependencies, allowed files/tools, permissions, outputs and acceptance criteria.
2. Assignee acknowledges scope and capability; reject if unsafe or underspecified.
3. Assignee executes, checkpoints risky work and records evidence.
4. Assignee submits outputs, changed artifacts, test status, risks and next action.
5. Receiver validates references and permissions, then accepts/rejects/requests clarification.
6. Ownership transfers only on acceptance. Delegation never grants more authority than the sender holds.
7. Coordinator updates project state and closes only under full-completion protocol.
