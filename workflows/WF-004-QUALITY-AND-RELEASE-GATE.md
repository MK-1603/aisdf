# WF-004 — Quality and Release Gate

1. Confirm approved release scope and baseline commit.
2. Verify requirement-to-test traceability.
3. Run applicable unit, integration, end-to-end, accessibility, performance and security checks.
4. Review dependency/license/secret risks and migration/rollback plan.
5. Perform independent verification for critical acceptance criteria.
6. Aggregate PASS/FAIL/NOT_RUN/BLOCKED/NOT_APPLICABLE/WAIVED statuses.
7. Obtain release authorization from the designated owner.
8. Deploy only through authorized environment and tool capabilities.
9. Run post-deploy smoke/health checks; record actual result and rollback decision.
10. Publish release and completion records with residual risks.
