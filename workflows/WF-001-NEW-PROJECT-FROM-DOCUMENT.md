# WF-001 — New Project from Document

## Goal
Convert a supplied project document into an approved baseline and controlled implementation plan.

## Stages and gates
1. **Intake:** E-001, E-002. Gate: mode and source inventory confirmed.
2. **Problem/product:** E-003, E-006–E-016. Gate: problem, stakeholders, requirements and acceptance criteria approved.
3. **Experience:** E-017–E-022. Gate: UX/UI scope and handoff accepted where applicable.
4. **Technology/architecture:** E-023–E-030. Gate: alternatives, compatibility, architecture and security decisions approved.
5. **Knowledge/tool readiness:** E-031–E-034. Gate: sources fresh; tool capabilities verified or marked unverified.
6. **Plan:** E-035–E-042. Gate: work units, dependencies, permissions and approvals assigned.
7. **Build/verify:** E-043–E-050. Gate: required tests and independent checks evaluated.
8. **Release/operate:** E-051–E-056. Gate: release authorization and production evidence exist.

## Outputs
Project profile, PRD, feature catalogue, acceptance criteria, design/architecture records, risk register, execution plan, test strategy, release record and completion report as relevant. No empty placeholders.
